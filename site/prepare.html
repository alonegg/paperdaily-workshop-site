会前准备：注册、安装与连通检查

请带笔记本电脑。按顺序完成账号、两个skills与一次查询；已有的配置可以先检查，避免重复安装。

1. 用学校邮箱注册 PaperDaily

  1. 打开注册页面，填写学校邮箱，按提示完成注册。
  2. 打开验证邮件完成邮箱验证；未收到时检查垃圾邮件。
  3. 在账号设置核对机构资格、期限与每日额度。有效机构成员可享每日300积分；仅邮箱后缀不能保证资格，以账号显示为准。权益说明

主站与Ask共用主站账号；RiD按其自身登录、资料连接与处理规则使用。

2. 在 WorkBuddy 导入两个 skills

尚未安装客户端，可从WorkBuddy官方入口下载安装。已有可用PaperDaily MCP的参与者也可直接进入连通检查。

下载 paperdaily.zip下载 deep-research.zip
  1. 进入“专家·技能·连接器 → 技能 → 添加技能 → 上传技能”。
  2. 分别选择两个完整ZIP。不要只上传SKILL.md，也不要上传整个仓库压缩包。
  3. 在“已安装”中启用 paperdaily 和 paperdaily-deep-research。
  4. 新建任务，使本次任务读取技能说明。

入口截图来自课堂准备时的实测版本；不同版本界面可能略有变化。

3. 检查运行条件与本机凭证

两个skills脚本需要 Python 3.10或以上。图形界面导入无需先装Git或uv。可请助教或自己的Agent检查依赖；缺少时按本人系统情况安装。

在PaperDaily“账号设置 → API Keys”创建只读key，选择 read:paper、read:digest，由本人填入本机配置。key不发群、不贴聊天、不截图。

展开配置路径与示例

macOS/Linux：~/.paperdaily-cli/env；Windows：用户主目录下 .paperdaily-cli\env。文件名是env，不是env.txt；已有配置先检查。

export PD_BASE="https://www.paperdaily.org/api/v1"
export PD_KEY="<仅在本机填写你的key>"

macOS/Linux目录与文件分别设置仅本人可访问的权限（700/600）；Windows使用本人可访问的文件权限。MCP连接器配置与skills本机env是不同入口。

查看完整安装说明、MCP可选路径与排查方法 →

4. 新建任务，复制这条自检指令

完成标志：查看实际工具调用和返回结果，确认查到了目标论文。只说“安装完成”或凭记忆介绍论文，不算连通检查。

未完成时记录卡在哪一步，携带电脑到现场协助处理，无需发送凭证。
